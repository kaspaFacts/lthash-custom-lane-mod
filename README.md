# LtHash Custom Modulo Benchmarking Suite ($M = 65,521$)

This standalone repository isolates and benchmarks the raw arithmetic performance of branchless prime modulo arithmetic ($M = 2^{16} - 15 = 65,521$) against standard native 16-bit wrapping ($M = 2^{16} = 65,536$).

It includes both **single-lane** and **1,024-lane vector** arithmetic operations, using a **precomputed memory table** to eliminate all PRNG and hashing overhead during benchmark timing.

## 1. How to Run Integrity & Net-Zero Tests

To run the standard unit tests and verify that single-lane & 1,024-lane additions/subtractions return to **exact net-zero (`0`)**:

```bash
cargo test
```

To run the interactive CLI verification harness:

```bash
cargo run --release
```

---

## 2. How to Run Microbenchmarks

To execute the microbenchmarks with native CPU SIMD vectorization (AVX2 / AVX-512) enabled:

```bash
RUSTFLAGS="-C target-cpu=native" cargo bench
```

### What the Benchmarks Measure:

1. **Single Lane Operations:** Iterates through 10,000 single `u16` lane additions and subtractions to measure pure ALU instruction cycle costs.
2. **1024-Lane Vector Operations:** Measures throughput for full `[u16; 1024]` accumulator state updates.
3. **Net-Zero Verification:** Every benchmark iteration automatically asserts that adding $N$ elements and subtracting $N$ elements lands at `0` (triggering an immediate panic if non-zero).

## 3. Results Inspection

After running `cargo bench`, open the interactive HTML performance report generated by Criterion in your browser:

```bash
# On macOS:
open target/criterion/report/index.html

# On Linux:
xdg-open target/criterion/report/index.html
```
